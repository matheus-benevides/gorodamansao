> **O Sabor da Festa. 0% Estimulantes. 100% Vibe.**

O **Goró da Mansão** é um sistema de e-commerce completo e imersivo, focado em bebidas energéticas premium. Desenvolvido com uma estética moderna (Glassmorphism) e animações fluidas, o projeto oferece uma experiência de usuário (UX) de alto nível, desde o catálogo até a gestão de pedidos.

## 🚀 Tecnologias Utilizadas

### Frontend
- **React + Vite**: Performance e rapidez no desenvolvimento.
- **Tailwind CSS**: Estilização moderna e responsiva.
- **Framer Motion**: Micro-animações e transições de página premium.
- **Context API**: Gestão de estado global do carrinho de compras.

### Backend
- **Node.js + Express**: Servidor robusto para API REST.
- **SQLite**: Banco de dados relacional leve e eficiente.
- **JWT (JSON Web Tokens)**: Autenticação segura para usuários.
- **Bcrypt**: Criptografia de senhas.

## ✨ Funcionalidades Principais

- **🛡️ Sistema de Autenticação**: Cadastro e Login seguros com persistência de sessão.
- **🛍️ Catálogo Sensorial**: Exibição de produtos com detalhes dinâmicos e cores exclusivas.
- **🛒 Carrinho em Tempo Real**: Adição, remoção e cálculo automático de frete (Grátis acima de R$ 500).
- **👤 Perfil do Usuário**:
    - Edição de dados pessoais (Nome, E-mail, Avatar).
    - **Gestão de Endereços**: Salve múltiplos locais para entrega.
    - **Métodos de Pagamento**: Cadastro seguro de cartões.
- **📦 Histórico de Pedidos**: Acompanhamento detalhado de todas as compras realizadas.
- **💳 Checkout Inteligente**: Fluxo de finalização de compra integrado com os dados salvos do usuário.

## 🛠️ Como Executar o Projeto

### 1. Pré-requisitos
Certifique-se de ter o [Node.js](https://nodejs.org/) instalado em sua máquina.

### 2. Clonar o Repositório
```bash
git clone https://github.com/matheus-benevides/gorodamansao.git
cd gorodamansao
```

### 3. Instalar Dependências
```bash
npm install
```

### 4. Iniciar o Backend
```bash
node server/index.cjs
```
O servidor estará rodando em `http://localhost:3001`.

### 5. Iniciar o Frontend
```bash
npm run dev
```
O app estará disponível em `http://localhost:5173`.
